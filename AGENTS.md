# Repository scope

Own reusable CI/CD workflows, actions, publication/security gates and their tests.
Project migration ledgers, reports, inventory generators and acceptance evidence belong in the existing local Legacy.Maliev.MigrationTracking repository.
Never recreate migration/ or its retired generators from stale worktrees or automation instructions. Preserve historical evidence links and source SHA provenance. Relocation does not establish runtime parity.
Do not publish the local tracking repository without explicit authorization. Preserve unrelated work and workflow interfaces. Validate Release builds, contract tests, formatting and relevant security checks before committing. No merge or deployment without approval.
